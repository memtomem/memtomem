# 프로젝트 업무별 memtomem 체험

개발자에서 PM·기획자·새 팀원으로 활용을 넓히는 세 가지 업무 패키지입니다.
Markdown 자료를 저장·검색하고 원문을 확인하는 기존 기능 위에서 동작합니다.
별도 웹 서비스나 새로운 저장 형식을 추가하지 않습니다.

| 업무 | 첫 질문 | 따라 하기 |
|---|---|---|
| 개발 작업 이어가기 | 어디까지 했고 다음에 무엇을 하지? | [인계 기록과 새 세션 검색](../../examples/workflows/handoff/README.md) |
| 제품 의사결정 기록장 | 왜 결정했고 지금도 유효한가? | [결정·대안·변경 배경 확인](../../examples/workflows/decisions/README.md) |
| 프로젝트 이해·온보딩 | 이 기능은 어떻게, 왜 이렇게 동작하지? | [문서·코드·설정 근거 찾기](../../examples/workflows/onboarding/README.md) |

## 시작하기

[공통 실행 안내](../../examples/workflows/README.md)에 따라 합성 자료로 먼저 체험하세요.
Python 3.12 이상이 필요합니다. 최초 설치 후 기본 검색에는 API 키·LLM·임베딩 모델이 필요 없습니다.
임시 저장소를 사용하므로 기존 자료와 AI 도구 등록을 변경하지 않습니다.

자기 자료로 옮길 때는 패키지의 양식을 복사해 작성하고 해당 문서 폴더만 색인합니다.
원문 확인 후 새 판단을 저장하고, 문서가 바뀌면 재색인합니다. 원하면 기존 웹 UI나
[MCP 클라이언트](mcp-clients.md)를 사용하세요. 원문의 상태와 적용 범위를 확인하는 일은
검색 순위만으로 대신할 수 없습니다.

## 실제 업무에서 확인하기

패키지마다 검색 과제 10개와 사람용 해석 기준을 제공합니다. 저장소 격리·재색인·출처 검색의
자동 검증과 실제 AI 해석·사용자 효과를 별도로 기록합니다.
[2주 파일럿 안내](../../examples/workflows/pilot/README.md)를 따라 자기 자료 첫 성공,
다음 주 재사용, 업무 시간, 동료 유입을 측정할 수 있습니다.
기준은 실험 설계이며 아직 사용자 성과를 측정한 결과가 아닙니다.
