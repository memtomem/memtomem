# 작업 인계 양식

복사한 뒤 빈 항목을 채우고 안내 문장은 지우세요. 이 양식 자체는 색인하지 않습니다.

- 주제와 검색 식별어:
- 프로젝트 경로와 작업 브랜치:
- 관찰한 commit/revision 및 작업 폴더 변경 상태:
- 기록 시각과 작성자:
- 완료한 작업:
- 확정된 결정과 원문 경로:
- 실제 실행한 검사·실행 시각·결과·로그 위치:
- 실행하지 못한 검사와 이유:
- 다음 행동과 필요한 확인:
- 보류·미확인 사항:
- 재개 시 현재 상태와 대조한 결과:

인계 기록을 저장했다고 테스트가 실행되거나 다음 변경이 승인되는 것은 아닙니다.
