# 결정 기록 양식

복사해 작성한 문서만 색인합니다. 상태와 관계는 이 문서의 업무 기록이며 memtomem의
별도 승인 엔진이나 자동 상태 변경 기능이 아닙니다.

- 결정 ID와 주제 식별어:
- 상태: 제안 / 채택 / 대체됨 / 철회됨 중 하나
- 결정일: 미확정이면 미확정
- 작성자:
- 채택 확인자와 확인 근거: 제안이면 미확정
- 적용 범위·효력 시작일:
- 결정 내용:
- 채택 이유:
- 검토한 대안과 선택하지 않은 이유:
- 근거 원문 경로 또는 URL과 관찰 날짜:
- 이전 결정 링크: 없으면 없음
- 대체한 후속 결정 링크: 없으면 없음
- 담당자에게 확인할 질문·충돌·근거 부족:

변경 시 새 문서와 이전 문서의 대체 링크·상태를 함께 검토하고 둘 다 재색인하세요.
같은 범위의 채택 기록이 충돌하면 해결 전까지 미확인으로 취급합니다.
