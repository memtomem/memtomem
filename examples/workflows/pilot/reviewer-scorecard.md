## 패키지 집계

- 모집 인원 / 이탈·미응답 인원:
- 자기 자료 첫 성공 인원 / 2주 차 실제 재사용 인원:
- 정확하게 완료한 시간 비교 짝 수 / 제외 이유 / 절감률 중앙값:
- 출처 오류 수 / 잘못된 결정 확정 수:
- 추천 인원 / 실제 신규 유입 인원 (중복 제외):
- 미측정 지표와 증거 한계:
- 후속 판단: 통과 / 개선 후 재시험 / 판단 유보

빈 값은 0이나 통과로 취급하지 않습니다. 사용자 행동과 원문 해석 결과는 자동 검증 보고서와 별개입니다.
