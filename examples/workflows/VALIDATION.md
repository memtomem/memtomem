## 리뷰 후 보강

- 데모 CLI의 네 가지 선택지와 모든 데모 질문을 평가 과제에 연결하는 회귀 테스트가 있습니다.
- 같은 청크 안의 정책 값·행동·코드 조건을 확인합니다. 빈 조건과 숫자 접두 일치도 거부합니다. 검색어만 남거나 다른 청크에서
  조각을 가져오면 회귀 테스트가 실패합니다. 질문 30개는 고유 검색 경로 25개와 중복을 제외한 원문 24개를 사용합니다.
- 제품 샘플 8개의 파일 목록·해시를 확인하고 변경된 자료는 임시 저장소를 만들기 전에 거부합니다.
  문서의 갱신 명령은 같은 함수를 사용하며 JSON·하위 폴더 추가 및 LF/CRLF 모사 회귀 테스트가 있습니다.
- `.venv-workflows/`는 Git 제외 대상입니다. CI와 개발 안내에 실행기 린트 범위를 추가하고,
  CI의 최소 설치 환경에서 `demo.py --validate`를 실행하도록 연결했습니다.
- CI와 같은 린트 범위에서 검사와 포맷 확인이 통과했습니다(954개 Python 파일).
  원격 CI 실행 결과는 아직 없습니다.
